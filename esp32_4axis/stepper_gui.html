E-STOP ENGAGED — all motion blocked. Press E-STOP again to release.
WIFI — type the board's hostname or IP in the box and press WIFI. The firmware prints both on boot, and IP reprints them.
USB — Chrome or Edge on desktop (Web Serial). Serve this file over http://localhost — from the folder, run python -m http.server 8000 and open http://localhost:8000/stepper_gui.html. Opening it directly as a file:// URL will not be allowed to reach the serial port. Close the Arduino Serial Monitor first, or the port will be busy.
