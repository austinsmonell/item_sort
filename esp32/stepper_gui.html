4-AXIS STEPPER CONTROL

E-STOP ENGAGED — all motion blocked. Press E-STOP again to release.
Chrome or Edge on desktop required (Web Serial). Serve this file over http://localhost — from the folder, run python -m http.server 8000 and open http://localhost:8000/stepper_gui.html. Opening it directly as a file:// URL will not be allowed to reach the serial port. Close the Arduino Serial Monitor first, or the port will be busy.
